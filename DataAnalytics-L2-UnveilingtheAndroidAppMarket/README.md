# Google Play Store Analysis

## Overview

This project performs an Exploratory Data Analysis (EDA) of the Google Play Store to understand the Android app market.

The analysis focuses on app categories, ratings, size, installs, pricing, estimated revenue, and user review sentiment.

## Objectives

- Analyze the distribution of apps across different categories
- Study app ratings and average ratings by category
- Analyze the relationship between app size and installs
- Compare free and paid applications
- Analyze the price distribution of paid apps
- Estimate revenue generated by paid apps
- Perform sentiment analysis on user reviews
- Identify positive and negative user feedback across categories

## Datasets

Two datasets are used:

- `googleplaystore.csv` – Contains information about Google Play Store applications
- `googleplaystore_user_reviews.csv` – Contains user reviews and sentiment-related information

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- TextBlob
- Google Colab / Jupyter Notebook

## Project Workflow

### 1. Data Loading

The Google Play Store app dataset and user reviews dataset are loaded using Pandas.

### 2. Data Cleaning

The following preprocessing steps are performed:

- Removed duplicate records
- Cleaned the `Installs` column by removing commas and `+`
- Converted installs into numeric values
- Removed `$` from the `Price` column
- Converted price values into numeric format
- Replaced `"Varies with device"` in the `Size` column with missing values
- Converted app size into numeric values
- Removed reviews with missing review text

## Analysis Performed

### 3. Category Analysis

The number of applications in each category is calculated and visualized using a bar chart.

This helps identify categories with a larger number of applications and higher competition.

### 4. Ratings Analysis

The distribution of app ratings is analyzed using a histogram.

Average ratings are also calculated for each app category and visualized using a horizontal bar chart.

### 5. Size and Installs Analysis

The relationship between app size and number of installs is analyzed using a scatter plot.

Correlation between app size and installs is also calculated.

### 6. Pricing Analysis

Apps are divided into:

- Free
- Paid

The number of free and paid applications is visualized.

For paid applications, the price distribution is analyzed using a histogram.
