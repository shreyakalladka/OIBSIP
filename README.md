# OIBSIP Data Analytics Projects

## Project Summary

This repository contains three Data Analytics projects completed using Python and Google Colab. The projects focus on **Exploratory Data Analysis of Retail Sales, Android App Market Analysis, and Wine Quality Prediction**. The datasets were cleaned, analyzed, visualized, and used to identify meaningful patterns and insights. Machine learning techniques were also applied for wine quality prediction.

## Tools & Technologies

Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn, Google Colab

## Projects

* **EDA Retail Sales** – Analyzed retail sales trends, customer behavior, and product performance.
* **Unveiling the Android App Market** – Analyzed app categories, ratings, reviews, installs, and pricing.
* **Wine Quality Prediction** – Analyzed wine characteristics and built a machine learning model to predict wine quality.
